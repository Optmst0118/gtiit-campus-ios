# 2.0.4-beta.5 · build 78

2026-10-27。

- 我的页通知中心／设置仍共用系统液态玻璃背景，移除各按钮额外的 44 点内容 frame，恢复与预约页相同的原生工具栏图标尺寸与间距。系统负责点击区域。
- 登录检查继续每次冷启动后台执行。普通通知中心只显示已检测到需要重新登录的网站；已登录、检查中、无法连接及未知状态不占用消息列表。
- 作业与预约栏目仅在有对应消息时出现。全部为空时显示单一“暂无新通知”状态，不保留空模块或缓存入口。
- 右上角 Beta 菜单中的“显示全部通知项目”开关跨启动保存。开启显示所有五站检测状态、作业／预约分类和本地缓存入口；关闭恢复仅消息模式。Beta 展开项不计入铃铛待办数量。
- 用一致的 Unix 时间精度判断截止边界，避免 Date 来回转换的微小舍入误差在恰好 24 小时时漏掉一条消息。
