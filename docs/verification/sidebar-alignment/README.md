# iPhone 横屏收起侧栏按钮对齐

2026-10-26，2.0.2-beta.2 build 71，前置提交 314cddf。

## 修改

横屏收起时，开关原先叠加了 split view 和 window 的横向安全距离，向右偏移；顶部固定 +8pt 也没有跟随右侧原生玻璃按钮的实际中心。

现在将窗口安全区域转换到 split view 坐标，仅保留一次安全距离及 20pt 内容边距；读取当前可见导航栏右侧 UIControl 的实际中心线定位 44pt 开关。没有右侧控件时按导航栏中心定位，没有可见导航栏时沿用安全区顶部定位。保留展开侧栏原生导航按钮和 iPad 的现有位置，不增加玻璃背景层，不改变 WebView 或导航实例。
