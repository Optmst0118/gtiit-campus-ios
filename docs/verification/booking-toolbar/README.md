# 预约横屏切换控件留白修复

2026-10-26，2.0.2-beta.2 build 71。

原先任何 Sidebar 布局都插入 64pt 空白 ToolbarItem；展开侧栏仍保留空位，且 iOS 26 将空位并入相邻的场所切换玻璃背景。

现在 Root 传递实际收起状态，展开时不预留空位；收起时 iOS 26 占位不共享玻璃背景，并收紧至 24pt（系统额外加入原生 item 边距）。旧系统保留 64pt。练习房／体育场馆标签按固有宽度布局，44pt 高度不变。原生预约页与网页模式使用同一占位组件。
