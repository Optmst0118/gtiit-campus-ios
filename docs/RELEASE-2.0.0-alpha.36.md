## 点击回归修复

学习与预约的原生 Button 使用了带额外 TapGesture 的卡片样式，导致标签手势抢占按钮动作。移除该手势；样式只负责按压缩放，触感由已接受的按钮动作触发。通过独立模拟器的真实坐标点按确认：学习 Homework 2 → 详情、预约查找可用时间 → 官方登录页、练习房分类 → 房间列表、D4-103-9 → 对应详情。未代替用户完成预约或提交。

## 本轮整体改进

- 保留四站并发预加载；统一跨站、摘要和快捷入口的可见页面路由，保护编辑页面的返回行为。
- Moodle 普通刷新保留30分钟缓存、失败退避；课程目录与已完成／远期详情可复用6小时。手动刷新强制重新核对。支持关注未匹配本地课表的课程。
- 本地课表、考试和作业摘要压缩层级；其他课程和工具放在二级页。
- PDF 整个玻璃下载按钮按住放大至1.065、松手回弹；已保存按钮禁用，避免重复保存。统一触感强度、语义和重复抑制。
- Widget 独立选择方向和服务日历，提前生成发车切换节点；本地诊断只记录聚合计数。
- 工程生成器、检查器与CI覆盖Widget和完整WebKit回归。
