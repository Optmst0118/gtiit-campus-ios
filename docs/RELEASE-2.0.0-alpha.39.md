# 2.0.0-alpha.39 · build 56

2026-10-24，基线`fc86c3e`（alpha.38）。

## 月历

月份选项使用本地化年月格式，不再显示某月1日。单选Picker标记当前显示月份，避免多个按钮伪装成选择项。月份内容使用系统分页ScrollView，可左右拖动；箭头切换带短吸附动画，月份菜单和翻页共享选中值。沿用每月六行的固定空间与假期背景。支持减弱动态效果。

## 整周课表

日期卡片在屏幕中间吸附，包括首尾日期。当前选中日与今天加深整个圆角矩形背景，课程内容保留。普通手势最多吸附到相邻一天；横向速度达到1200点/秒时切换七天，保持相同星期。切换触发选择触感。周按钮沿用相同选中和滚动逻辑，回到本周回到今天；大字号仍保留纵向排版。

采用原生UIScrollView减速目标控制滚动结束位置，避免另加会抢占点击的拖动手势。边界在可浏览日期范围内钳制，不出现空白目标。

## PDF下载

保存成功后，原圆形下载控件展开为60点高的横向圆角玻璃条，显示已下载、分享和在文件中显示。分享使用已取得的本地内容；文件位置使用系统Files浏览界面并以实际保存文件夹为初始目录，不再次下载、不改变默认位置。外部文件服务可能由系统决定最终浏览位置。

会话独立保留永久保存URL，关闭预览只清理临时内容。已下载PDF重开时同样显示操作条。VoiceOver为两项操作提供名称；较早系统及减弱透明度使用材质或实色背景。
