# GTIIT 1.3 (7) · 2026-10-21

签名 Release 已覆盖安装到用户 iPhone Air（iOS 27.0.1），devicectl 确认安装和启动成功。保留原 bundle identifier 与持久化网页容器，没有卸载或清除手机登录数据。

## 改进

- 从后台划掉后重新启动，先显示四站预加载界面；门户、Moodle、练习房、体育站点并行准备，进入标签后复用同一批 BrowserModel 和 WKWebView。
- 有效会话由原 WebKit 持久化容器恢复。Moodle 在官方登录页尝试一次既有 Office 365 SAML 入口，不读取或代填密码。首次登录、会话失效、验证码及多因素验证仍需用户完成；页面就绪不宣称登录成功。
- 启动最多等待 10 秒，独立计时避免网页脚本无响应造成卡住；“直接进入”随时结束遮罩，未完成的正常网页请求继续。设置 → 通用可关闭启动预加载。
- 首次使用先完成引导；启用隐私锁时，解锁后才启动预加载。正常启动不主动清缓存。
- 删除预约页“练习房／讨论室”和“体育场馆”顶部原生免责声明，保留分类切换和官方网页。
- 1.2 的下载合并液态玻璃面板、自动隐藏、关于页信息整理、班车和图标改进继续保留。

## 验证

- 89 项实际产品源码与 WebKit 集成回归通过，包括四站就绪、密码表单识别、内核身份复用、只启动一次、截止与跳过行为、引导和隐私锁门控。结果见 verification/regression-results.json。
- 40 项班车独立检查此前通过，本次班车计算未改动。
- Debug 模拟器、签名 Release 真机两种最终构建通过；39 个 Swift 文件全部编译进入工程。结果见 verification/build-results-1.3.json。
- 全面屏模拟器实际观察到四站预加载状态与结束后预约页，顶部免责声明已消失。没有适配非全面屏。
- 真机安装与启动证据见 verification/device-install-1.3.json。
