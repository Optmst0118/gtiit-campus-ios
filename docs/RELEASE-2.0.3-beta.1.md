# 2.0.3-beta.1 · build 72

2026-10-26。前置提交 16c2649，属于导航布局／动画修复，按修订版本递增。

侧栏收起时，侧栏开关与返回按钮现在共用一个持久的 UIGlassContainerEffect。进入页面后返回按钮从开关右侧分离，回到一级页面后融合收回；继续深入只保留一组按钮。按钮动作仍分别负责侧栏和页面返回。

共同的 nativeNavigationSurface 为设置、下载、校历、课表、Moodle、预约及网页 push 注册导航状态；网页内部历史及未提交表单仍使用原有返回逻辑。展开侧栏、竖屏紧凑布局和独立弹窗恢复原本的系统导航。保留原生交互返回识别器，页面切换时拆除代理链，避免重复进入后形成循环。

仅导航按钮使用玻璃容器；状态栏／页面 canvas、WebView 存储、网站登录与数据模型未改动。较早 iOS 使用系统材质，减弱动态效果时直接更新按钮状态。

验证和截图见[导航玻璃验证记录](verification/navigation-glass/README.md)。
