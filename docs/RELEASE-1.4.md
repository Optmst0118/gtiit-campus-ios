# GTIIT 1.4 (8) · 2026-10-21

签名 Release 已覆盖安装到用户 iPhone Air，devicectl 确认安装并启动成功。

## 改进

- 仅学习／Moodle 的 PDF 改成先预览。沿用当前 WebKit 响应接收临时内容，保留 POST、一次性链接、登录和子窗口上下文；没有额外 GET，也不在预览时生成正式下载记录。
- 原生 PDFKit 支持阅读、缩放和旋转；右下角 48 点蓝色液态玻璃按钮显式保存，成功后勾选并防重复。关闭未保存预览清理临时内容。
- 浮窗和下载管理均使用独立的原生预览控制器。浮窗自动收起不再销毁预览；呈现过渡等待处理了新窗口和菜单动画，快速重复打开被合并。
- 下载位置行可用系统选择器更改新下载的默认目录，包括系统支持的本机、iCloud Drive 和第三方文件服务。已有文件不迁移，进行中的任务继续使用创建时的位置；可恢复默认 Downloads。
- 下载索引与默认目录分离，并兼容旧记录。外部目录使用授权书签与协调读写，同名编号，不覆盖已有文件；授权失效或目录不可用明确报错，不静默回退。
- 列表只显示小图标和文件名；右上角切换缩略图网格。名称自然排序、大小和时间均支持升降序，视图与排序跨启动保存。长按提供预览、分享、重试、取消及确认删除，没有左右滑动删除。
- 保留策略收进管理菜单；外部文件不参与自动清理及“清理本机下载”，手动删除仅针对当前文件。
