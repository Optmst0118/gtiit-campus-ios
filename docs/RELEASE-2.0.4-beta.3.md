## 作业提醒时间

设置 → 学习与课表 → 作业提醒 → 未提交作业提醒时间：24 小时、2 天、5 天、1 周。默认 24 小时，偏好跨启动保存。修改时以原通知标识替换尚未送达的排程；已送达的同一作业／截止时间不会因更换提前时间而重复通知。原有索引可兼容读取。

沿用已登录 Moodle 的当前学期／活跃课程缓存和 30 分钟同步。已进入所选提醒窗口的未提交／草稿在检测后提醒；已知未来截止时间交给系统排程。最多保留 32 条作业提醒，受全 App 通知预算约束。新作业、外部提交与改期需要下一次成功同步，未新增后台持续爬取。

## 班车

下一班默认显示在靠上第二行，上方保留上一条计划发车。第一班与末班有可滚动边界处理；按方向、日期、教学周继续选择有效发车。三款高亮方案见 [外观审核](design/shuttle-beta3/README.md)。

## 服务中心

新增「我的 → 常用入口 → 服务中心」，已有用户默认加入一次，可在设置 → 通用移除后保持移除。独立持久化 WebKit 会话，保留原四个校园系统的登录数据；首次启动四站登录流程不变。

已通过用户新开的 Safari 窗口核对 Zammad 我的工单字段和菜单路由。客户工单表转换为原生列表；点击激活原网页行，详情、回复、附件和新建仍保留当前网页会话。顶部提供我的工单、新建工单、知识库，刷新位于更多菜单。未识别到表格、认证页面或结构变化时保留网页，避免展示虚假空列表。

网页配色纳入统一深浅色背景，表单采用系统字体和适合手机的输入字号。工单列表仅在内存展示，没有把用户真实工单内容写入测试或发布材料。
