# 2.0.0-alpha.38 · build 55

2026-10-24，基线 `9a88c37`（alpha.37）。

## 校历

- 用SwiftUI日期网格替换只能在日期下加装饰的UICalendarView，保留原生按钮、菜单、VoiceOver与月份导航。月份卡内20点留白，周一至周日七等宽列，固定六行日期空间。
- 放假日采用系统红色16%透明圆形背景；选中日另外使用蓝色描边，今天使用加粗。
- 周六、周日均为休息日。国内假期及逾越节沿用核实后的原始日期；其他节日不新增假期标记。
- 按用户确认补上考试结束次日至下一学期开学前一天的学期间假期。汇总同学期最后一次已核实考试，跨学年匹配下一次开学，排除考试结束日及开学日。最后一份校历的假期只显示到原表末尾2027年7月31日，不推断后续开学日期。
- 例如2026年9月25日至10月11日、2026年2月28日至3月1日；2026年7月24日至26日结束后，7月27日夏季学期开始。
- 对照本机两份原始PDF的版面与日期。原件不公开再分发。

## 实时活动

- 锁屏与灵动岛展开态统一发车日期、时间和倒计时的右边缘；计时Text本身设为右对齐，避免外层frame靠右但数字仍靠左。
- 轨迹采用细线、起点、直接由SwiftUI绘制的矢量侧面巴士和向右箭头，作为方向示意，不映射车辆位置，也不持续循环动画。
- 使用14点锁屏内容边距、系统字体与等宽数字，紧凑灵动岛保持短方向标签。
- 参考：[Apple Live Activities HIG](https://developer.apple.com/design/human-interface-guidelines/live-activities)，包括配送进度案例、标准边距及紧凑布局原则。

## 验证

日期边界、周末、跨年学期间隔及上海时区格式已纳入集成回归。完整结果见[回归记录](verification/regression-results.json)。318项集成回归通过。独立模拟器已检查浅色／深色月历、日期选择与独立辅助功能标签，以及两方向共享锁屏内容的实际布局和矢量巴士可见性。灵动岛扩展通过设备构建，系统岛的最终呈现仍由iOS管理；新旧实时活动使用兼容的attributes，系统展示新扩展可能需要重新开启活动。
