# GTIIT 1.8 (12)

- Web content extends beneath the system Liquid Glass tab bar. A stable UIKit controller registers WebKit’s actual scroll view with the bottom bar; automatic scroll insets keep the last page action above the controls. No fake glass layer or fixed tab-bar padding is used.
- The four campus websites share the native Me canvas, `#0E141C`, in dark adaptation. Native WebKit backdrops and Dark Reader’s final page-canvas override use the same color. Elevated content, booking status colors, form values, media and the original-colors preference remain intact.
- Me has independent local timetable and Moodle upcoming cards. Calendar is in the two-column shortcut grid. Shortcuts use soft sky-blue gradients with deep-blue labels and no site badges or play controls.
- Downloads, Settings and Help & Diagnostics retain grouped list rows, together at the bottom, following the final user correction.
- All four websites’ common loading error screen now explains campus Wi-Fi and the school’s VPN connection in aTrust. DNS, connectivity, timeout, certificate, process and main-document HTTP errors are covered; popup windows show the same recovery view. Specific error messages remain visible. The app does not connect a VPN or change its configuration.
- `atrust://` is queried only at runtime. If a handler exists, the error page can open it; otherwise it gives manual opening instructions and the official [aTrust App Store page](https://apps.apple.com/app/id1536711104). Direct iOS client launch is conditional, not claimed as verified on this phone. The scheme was found in the vendor’s installed desktop client metadata, and is not assumed to be supported by every iOS release.

Validation: 250 isolated regression checks passed. Checks cover exact web-canvas RGB values and restoration in all four sites; actual root-tab layouts extending to the screen bottom; end-of-page action visibility above the bar; and each site’s network and HTTP error handling. Me’s separate cards, final light-blue grid, bottom utility list and dark web content visible behind the real glass bar were visually reviewed using synthetic data. The palette preserves text contrast in light and dark appearance. Signed Release build and installation status are in `docs/verification/features-1.8.json`.

References: [Apple: adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass), installed UIKit SDK `UIViewController.setContentScrollView(_:for:)` documentation, and the vendor’s [aTrust App Store listing](https://apps.apple.com/cn/app/atrust/id1536711104).
