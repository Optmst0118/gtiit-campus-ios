# 1.6（10）本地交付记录

日期：2026-10-22。基于最新本地提交 `79d3f88`；安装前手机上为 `io.github.optmst0118.gtiit` 1.5（9），保持同一包标识覆盖升级。回溯起点：`gtiit-before-1.6`。没有回退此前网页校徽清理、滚动、原生菜单或下载管理调整。没有推送或发布到远端仓库。

## 新功能

- 我的 → 校历：两学年共 85 条来源事项，默认当前学年。近期事项、学年切换、原生月历圆点、假期倒计时、原文和原始 PDF。两份六月 31 日考期保留原文并标为待核实，结束日期为空；军训预留说明也不作为确认日期。文化节日不自动变为停课日，校历不控制班车教学周。
- 设置 → 提取课表到本地：在同一门户登录上下文中打开 Enrollments。一次性、只读提取正式选课的名称、代码、班组、星期、起止时间、楼栋和教室；排除预览、待新增、待删除项，不读取令牌、账号、成绩或网页原文，不请求未确认的 API。导入前核对学期与起止日期，已有课表替换需确认。页面或字段结构变化时停止导入，旧快照不受影响。
- 我的 → 本地课表：首页直接显示今天课程和下一节的日期、时间及教室；进入整周安排，水平分日，大字号使用纵向日列表。长教室信息完整换行。按已核实校历处理假期及补课星期，超出确认有效期不继续套用。临时停课和校方更新仍需用户重新提取。
- 课表存于受文件保护的 Application Support，排除系统备份，无服务器；删除入口需确认。网页 Cookie 清理与课表删除分别管理。
- 设置 → 语言：原生界面 English / 中文，505 条翻译，动态占位符、日期和快捷入口随语言更新。切换不改变网页语言、不重建网页、不重置导航。
- 关于 GTIIT：保留左侧 CampusMark 重绘图标。标题或卡片连续六次点击，解锁设置中的“以龙”；三视图透明贴纸从最后点击处弹出。SpriteKit 有边界、碰撞、回弹及压缩拉伸，最多 48 个物体，实际一次生成 36 个。支持收起；锁屏与后台时销毁，减弱动态效果使用三个静态视图。

## 校历来源

原始 PDF 沿用用户已下载的两份文件，字节保持不变，哈希见 `GTIIT/Resources/CampusData/sources.json`。本机安装包含原件；原件按仓库现有约定被 Git 忽略，不公开再分发。JSON 只保存校历事项；没有真实个人课程数据进入源码、测试或截图。
