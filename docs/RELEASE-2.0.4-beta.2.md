# 2.0.4-beta.2 · build 75

2026-10-27。新增 Moodle 截止提醒和班车详情下一班定位。

## 作业提醒

- 默认开启，在「设置 → 学习与课表 → 作业提醒」管理开关及系统通知权限。
- 沿用现有 Moodle 当期／活跃课程核对与 30 分钟刷新间隔。只对已核对为未提交或草稿、具有有效截止日期的作业排程；仅有日历事件且提交状态未知的不冒充待提交作业。
- 已进入截止前 24 小时窗口的作业首次检测后立即提醒；缓存中未来 7 天的已知截止时间可提前交给系统，关闭 App 后仍可按已排程时间提醒。
- 每个作业／截止时间提醒一次，受文件保护且排除备份的本机哈希索引跨启动去重。关闭、提交、改期、完整结果中移除、清除 Moodle 登录数据时，更新或取消对应通知；部分核对失败不会误删未核对课程的旧提醒。
- 通知点按打开对应 Moodle 作业；保留班车通知原有路由。权限拒绝时提供系统设置入口，不反复请求。排程失败可重试；本功能最多保留 32 条待发提醒，并计入全 App 通知预算。
- 新增作业与外部设备上的提交／改期，需要之后成功同步才能得知；没有后端常驻监控或保证 iOS 后台持续扫描网页。该说明保存在开发文档，不增加界面免责段落。

## 班车详情

- 按方向、教学周、当天星期与北京时间，选出最近的有效发车，使用对应天蓝／橙色背景、强调条及「下一班 · 今天／明天」标注。
- 打开详情和切换方向时以可视区域中心对齐下一班；时间跨过发车点后更新下一班。首末行也保留足够滚动空间，支持跨天、同时间独立车次与系统大字号。
- 保留必要的运营时间与校门信息，删除旧页脚冗余声明。

## 验证

- 完整独立回归 **433 项通过**，含 25 项新增截止通知测试：24 小时边界、过期、草稿、未知／已提交、去重、改期、部分结果、重启、权限、关闭／退出、容量、失败重试和偏好持久化。
- 项目一致性、本地化检查和 Debug Simulator 构建通过。
- 最后补充解锁时重新同步通知的入口后，重新完成签名 Release 构建和 App／Widget 版本、签名、Profile 校验。
- iPhone 17 / iOS 26.5 独立模拟器：确认两方向下一班居中、系统通知授权界面，以及模拟作业通知实际出现在通知中心。测试使用虚构课程，已清除送达的测试通知。
- 初次完整回归因设备停在横屏出现布局断言；恢复竖屏、结束额外测试设备后复跑通过。
- 实际课程后续提交状态、真实截止时刻通知及真机送达仍需在正常登录和授权后的使用中核对。
