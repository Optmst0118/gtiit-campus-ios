# 2.0.0-alpha.37 · build 54

2026-10-24，基线 `e014713`（alpha.36）。

## 修改

- 下载管理的列表左滑、列表长按和网格长按删除，均直接调用文件删除，不再显示二次确认。错误仍由原有文件操作提示呈现。
- 原有Moodle简化样式只匹配课程首页，作业及其他活动页面未覆盖。现在所有原生Moodle详情路由都安装同一套样式，范围限定在官方课程和`/moodle/mod/`活动路径，登录页面保持原有交互。
- 课程页与作业、提交、测验页隐藏重复站点导航，统一浅色`#F2F7FA`、深色`#0E141C`画布。保留活动说明、截止时间、附件、提交表单和测验操作。退出原生详情时移除样式。

## 验证范围

新增真实WebKit渲染回归，覆盖课程、作业、作业编辑提交、测验路径的背景和导航，并检查活动信息、表单值、按钮事件、深色画布、样式移除和登录页排除。本轮完整305项集成回归通过。完整结果见[集成回归记录](verification/regression-results.json)。

下载列表和网格分别长按删除独立测试PDF，文件数从2→1→0，未出现二次确认。未删除用户现有文件。Release签名构建、工程结构、本地化及扩展版本检查通过；build54覆盖安装并成功启动，保留原有数据。
